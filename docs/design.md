# 디자인 기준

## 1. 방향

Homelab Notes는 타이포그래피와 여백을 중심으로 한 개인 기술 저널이다. 홈랩·네트워크·보안 기록을 차분하게 읽을 수 있도록 편집물의 질서를 사용하고, 홈 첫 화면에는 점으로 구성된 `Alcedo` 워드마크를 둔다.

카드와 장식은 필요한 곳에만 사용한다. 프로젝트와 노트는 번호, 구분선, 제목, 짧은 설명으로 구분하며 실제 경력, 측정값, 운영 사실은 확인된 내용만 표시한다.

## 2. Ink와 Paper

기본 `ink` 테마는 짙은 먹색 배경과 따뜻한 미색 글자, 절제된 적갈색 강조색을 사용한다.

- 배경 `#141413`
- 본문 `#e8e6dc`
- 보조 글자 `#a3a199`
- 강조 `#c88169`
- 구분선 `#373732`

`paper` 테마는 같은 위계를 밝은 종이색으로 뒤집는다.

- 배경 `#eeeadf`
- 본문 `#242420`
- 보조 글자 `#646158`
- 강조 `#995139`
- 구분선 `#c9c3b6`

테마는 루트의 `data-theme` 값으로 전환한다. 색뿐 아니라 브라우저 `color-scheme`, 테마 색상, 파티클 팔레트가 함께 바뀐다. 사용자의 테마 선택은 로컬 저장소에 보관하고, 전환 애니메이션은 모션 감소 환경에서 생략한다.

## 3. 타이포그래피

영문 세리프와 워드마크에는 Instrument Serif의 regular·italic 파일을 자체 호스팅한다. 한국어 제목과 본문 세리프에는 Google Fonts가 제공하는 Noto Serif KR의 전체 한국어 범위를 WOFF2 유니코드 서브셋으로 자체 호스팅한다. `Korean` 패밀리는 400–600 가변 굵기 범위를 선언해 필요한 문자 서브셋만 브라우저가 가져오게 한다.

일반 UI 본문은 시스템 산세리프를, 라벨·번호·메타데이터는 시스템 모노스페이스를 사용한다. Instrument Serif와 Noto Serif KR은 각각 저장소에 포함된 SIL Open Font License 1.1 문서와 함께 배포한다.

## 4. 홈 화면

화면 순서는 헤더, 파티클 워드마크와 소개, 대표 프로젝트, 노트, Velog 안내, 푸터다. 본문 셸은 기본 최대 1,280px이며 큰 화면에서는 1,380px까지 확장된다.

히어로의 `.hero-stage`는 화면 폭에 따라 약 235–450px 높이를 가진다. `Alcedo` 텍스트 fallback을 항상 먼저 제공하고, canvas가 실제 프레임을 그린 뒤에만 fallback을 숨긴다. 파티클은 포인터에 반응해 흩어졌다가 원래 글자 형태로 돌아온다. 모션 감소 설정에서는 정적 프레임을 사용한다.

프로젝트 시각 자료는 선, 노드, 흐름 신호를 사용하는 기술 다이어그램으로 구성한다. Notes는 큰 이탤릭 제목과 구분선 목록으로 보여주며, Velog 영역은 기술 문서와 이야기 채널의 역할 차이를 설명한다.

## 5. 읽기와 반응형 기준

작은 화면에서는 내비게이션, 프로젝트, 노트, 푸터를 한 열로 재배치하고 가로 스크롤을 만들지 않는다. 표는 별도 스크롤 영역으로 감싸고, 긴 코드와 URL은 읽기 영역을 넘지 않게 처리한다.

키보드 포커스, 건너뛰기 링크, 검색 대화상자, 현재 위치 표시를 제공한다. 정적 검색, RSS, 글 목차, 코드 복사, 링크 복사 기능도 시각 체계 안에서 같은 색과 포커스 규칙을 사용한다.
